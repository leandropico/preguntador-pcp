# preguntador-pcp
Una app web destinada a practicar para el coloquio final de PCP en la FCEIA-UNR.

Contiene 194 preguntas hechas en clases de teoría, con la respuesta de la cátedra a dicha pregunta. Está pensado para aquellas personas que estudian solas, que sirva de compañero de repaso

<img width="737" height="328" alt="imagen" src="https://github.com/user-attachments/assets/d263dc12-ae3a-4e7a-a915-8bdb1b439239" />


El funcionamiento es simple:
- Hacer click en *Siguiente Pregunta* para mostrar una pregunta al azar.
- Pensar la respuesta que darías en el coloquio.
- Luego, para revisar si la respuesta es correcta hacer click en el botón *Mostrar Respuesta* para verificar
